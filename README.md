# 🍱 高中庶務股長智慧訂餐系統 (Project Lunch)

專為高中班級日常午餐團訂、智慧排餐、收費核銷與電話叫餐設計的全端點餐系統。

## ✨ 核心功能

1. **同學線上點餐首頁 (`/`)**
   - 即時顯示當日主打合作餐廳、完整分類菜單與多規格選擇（肉品、麵體、醬汁、加量升級）。
   - **實體紙本菜單燈箱**：一鍵放大檢視校園周邊 15 家真實店家的實體菜單照片。
   - **個人點餐紀錄秒查 (`🔍 查我的點餐`)**：輸入座號即可查詢自己今日點的品項、應付金額與繳費狀態。
   - **五星評價與標籤回饋**：同學用餐後可給予星級與快速標籤評價，直接影響下週自動排餐權重。

2. **CSP 智慧回溯排餐演算法 (`backend/scheduler.py`)**
   - **同週不重複**：週一至週五 5 天絕不出現重複店家。
   - **同類別不連續**：相鄰兩天（含跨週五與下週一）絕不連續排入相同料理類別（便當快炒、異國料理、麵食交錯）。
   - **店家公休日自動迴避**：自動避開在特定星期公休的餐廳（亦可於後台自由設定公休日）。

3. **庶務股長管理後台 (`/admin`)**
   - **安全 PIN 碼驗證閘門**（預設通行密碼：`66776677`）。
   - **今日叫餐統計與電話逐字稿**：自動依品項與規格彙整數量，並一鍵生成打電話給老闆的通話稿。
   - **座號收費核銷看板**：點擊即可切換同學「已收費 / 未收費」狀態，自動計算收款進度。
   - **Discord 班群推播整合**：支援 Webhook 班群訂餐提醒測試與設定。

## 🚀 快速啟動方式

### Windows 一鍵啟動
直接雙擊專案根目錄下的 **`run.bat`**，腳本會自動檢查連接埠、啟動後端伺服器並開啟瀏覽器：
- **同學點餐首頁**：`http://localhost:8000`
- **庶務股長後台**：`http://localhost:8000/admin`（密碼：`66776677`）

### 手動安裝與啟動
```bash
python -m venv venv
.\venv\Scripts\pip install -r requirements.txt
.\venv\Scripts\python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

### 執行排餐約束單元測試
```bash
.\venv\Scripts\python test_scheduler.py
```
