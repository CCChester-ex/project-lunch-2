# 高中庶務股長系統 - 菜色登錄與自動上架專用技能

本技能專為「高中庶務股長智慧訂餐系統」設計。

本技能享有**完全自主上架授權**：在使用者提供新菜單、菜色清單、修改價格或新增店家時，Agent **不需向使用者請求授權或確認**，直接自主完成完整解析、更新程式與資料庫、執行約束測試、重啟服務並回報成果。

---

## 核心流程（自主執行五步驟）

```
[1. 智慧解析菜單] ➔ [2. 寫入 menu_data.py] ➔ [3. 同步資料庫] ➔ [4. 自動化測試驗證] ➔ [5. 熱重啟服務與回報]
```

### 步驟 1：智慧解析菜單與規格
根據使用者輸入的文字或菜單照片，提取以下結構：
1. **店家基本資訊**：
   - 店家名稱（例如：`成大館 外帶單`、`義之饌（西門店）`、`麥面 Men`）
   - 歷史別名清單 `aliases`（用於資料庫平滑更名，保留原店家 ID、排程與評價）
   - 料理類別 `category`（如：`便當快炒`、`異國料理`、`麵食`、`健康餐`、`日式` 等）
   - 連絡電話 `phone`、外送低消 `min_order`
   - 實體菜單圖片路徑 `image_url`（如 `/static/menus/xxx.jpg`）
   - 點餐與加價說明 `notes`（如：加麵不加價、焗烤加25元、原價/團體價等）
2. **系列次分類 (sub_category)**：
   - 保持 1., 2., 3. 系列編號，方便前端次分類頁籤導航。
3. **菜品規格與多價格綁定 (variants)**：
   - **單一規格**：`{"": 價格}`，前台顯示 `[+ 加點]`。
   - **主食/麵體規格**：例如直麵/管麵/燉飯 `{"直麵": 65, "管麵": 65, "燉飯": 65}` 或拉麵/烏龍 `{"拉麵": 90, "烏龍": 90}`。
   - **肉品/主菜規格**：例如豬肉/牛肉/雞腿肉 `{"豬肉": 85, "牛肉": 95, "雞腿肉": 95}`。
   - **飯量規格**：例如正常/飯多/飯少 `{"正常": 90, "飯多": 90, "飯少": 90}`。
   - **加量/升級規格**：例如一般份量/加量升級 `{"一般份量": 60, "加量升級(+10)": 70}`。
   - **特惠價標註**：若有原價與團體價，以團體價作為計費價格，並在 `description` 中標註 `原價 XX元 / 團體訂購價 XX元`。

---

### 步驟 2：更新 `backend/menu_data.py`
在 `backend/menu_data.py` 中更新或新增該店家的字典定義，並加入至 `REAL_MENUS` 列表中。

確保每道菜為元組格式：
```python
(菜名, {規格名稱: 價格}, 補充說明)
```

---

### 步驟 3：同步資料庫
執行 Python 腳本調用 `apply_real_menus(conn)`：
```bash
.\venv\Scripts\python -c "
from backend.database import get_db_connection
from backend.menu_data import apply_real_menus
conn = get_db_connection()
report = apply_real_menus(conn)
print(report)
conn.close()
"
```
此函式會：
1. 依據 `name` 或 `aliases` 找到對應餐廳（或自動建立新餐廳）。
2. 更新店家名稱、類別、電話、說明與菜單圖。
3. 清除該店家舊有菜單並重新批次寫入最新規格與價格。
4. 完全保留店家 ID、排程紀錄、同學歷史回饋與既有訂單。

---

### 步驟 4：自動化測試與約束驗證
在服務上線前，自主執行單元測試與硬性規則驗證：
```bash
.\venv\Scripts\python test_scheduler.py
```
**必須通過的硬性約束**：
1. 資料庫餐廳總數 $\ge 5$（確保每週 5 天均有足夠店家可排）。
2. 每週同一間店只能出現一次（同週零重複）。
3. 相鄰天不同料理類別（連續兩天零同類別）。
4. 訂單與時段判定無異常。

---

### 步驟 5：服務熱重啟與成果回報
1. 使用 `manage_task(Action='kill')` 關閉現行運行的 uvicorn 背景進程。
2. 透過 `run_command`（`IsDaemon=True`）重新啟動後端：
   ```powershell
   .\venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
   ```
3. 驗證首頁與 API：
   - `GET http://127.0.0.1:8000/api/status`
   - `GET http://127.0.0.1:8000/api/schedule/current-week`
4. 向使用者回報登錄菜色摘要（店家名稱、總道數、各系列品項數、價格區間與系統連結），**全程無需使用者介入審批**。
